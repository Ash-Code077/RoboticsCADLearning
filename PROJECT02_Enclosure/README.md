# Enclosure
## Description
- **Software**: Autodesk Fusion 360
- **Status**: *Finished on 9/9/2026*
- **Fails**: Tried using bevels, chamfers, and fillets to acheive a well done rounded finish on the edge of the box.
- **What I Learned**: Emphasized on using MODIFY tools to acheive a rounded finish. Learned exactly how fillet worked; it works only on the edges chosen and doesn't affect any geometry besides the chosen geometry. Shell works by getting rid of a chosen face and hollowing the geometry beneath it. Made sure measurements were to chosen measurements beforehand using Inspect and measurement tools.
